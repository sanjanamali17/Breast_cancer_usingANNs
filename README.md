# Breast Cancer Wisconsin (Diagnostic) Prediction Using ANN (TensorFlow) Project Overview

This project implements an Artificial Neural Network (ANN) using TensorFlow to predict whether a breast tumor is malignant or benign based on medical features extracted from breast tissue images.
The system is designed as an AI-assisted screening tool to support medical professionals in early diagnosis and decision-making.

⚠️ Disclaimer: This application is intended for educational and research purposes only. It does not replace professional medical diagnosis.

### Problem Statement

Breast cancer is one of the leading causes of death among women worldwide.
Manual diagnosis based on medical imaging and measurements can be time-consuming, subjective, and prone to human error, especially when dealing with multiple tumor features simultaneously. There is a need for an automated, accurate, and reliable screening system to assist doctors in early detection and decision-making



### Proposed Solution

This project proposes an AI-based Breast Cancer Prediction System using an Artificial Neural Network (ANN) built with TensorFlow.
The system analyzes 30 tumor-related medical features and predicts whether a tumor is benign or malignant, along with a confidence score and medical guidance.

The solution acts as a decision-support tool for doctors, improving diagnostic efficiency while ensuring the final decision remains with medical professionals.


### Technologies Used

Programming Language: Python

Machine Learning Model: Artificial Neural Network (ANN)

Framework: TensorFlow / Keras

Web Interface: Streamlit

Data Handling: Pandas, NumPy

Visualization: Matplotlib

Report Generation: ReportLab (PDF)

### Model Performance

Model: Artificial Neural Network (TensorFlow)

Accuracy: ~97%

Dataset: 569 samples | 30 features

Task: Binary classification (Benign / Malignant)


This system demonstrates how AI can enhance healthcare by providing fast, accurate, and structured predictions, supporting doctors in early breast cancer diagnosis and improving patient outcomes.
